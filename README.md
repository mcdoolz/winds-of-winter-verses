# The Winds of Winter — Dynamic Corpus & Archive

This repository houses the dynamic verses, plot hole resolutions, cheeky book retrospectives, and achievements for the **Winds of Winter** authorship engine.

## Repository Organization
- `verses/`: Individual JSON nodes representing story branches, plot hole resolutions, choices, and epilogues.
- `achievements/`: Organized separately from verses. Contains combo milestone achievements and plot-hole resolution achievements.
- `books/`: Cheeky, sarcastic retrospectives of the 5 published books (*A Game of Thrones* through *A Dance with Dragons*) detailing their flagrant plot holes.
